Einige Elemente, die zuerst künstlich hergestellt wurden, hat man später auch in winzigen natürlichen Mengen gefunden.

Die entscheidende Korrektur lautet daher: Ein Element muss keine stabile natürliche Lagerstätte auf der Erde besitzen, um zum Periodensystem zu gehören.
