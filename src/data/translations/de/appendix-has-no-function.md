In der Evolutionsbiologie bedeutet „rudimentär“ nicht zwangsläufig völlig nutzlos. Eine Struktur kann einen großen Teil ihrer ursprünglichen Funktion verlieren und dennoch andere Funktionen behalten oder neu entwickeln.

Einige vermutete Rollen im Mikrobiom werden weiterhin erforscht. Korrigiert wird die absolute Behauptung, der Wurmfortsatz habe überhaupt keine Funktion.
