Welle-Teilchen-Dualismus bedeutet nicht, dass ein Photon buchstäblich eine winzige klassische Kugel ist, die sich gelegentlich in eine wasserähnliche Welle verwandelt. Quantenobjekte werden durch einen Rahmen beschrieben, dessen Messergebnisse beide Arten von Verhalten zeigen können.

Die klassische Wellenoptik bleibt für viele makroskopische Anwendungen äußerst genau.
