Eine sorgfältig geführte Folgebefragung kann durchaus zusätzliche nützliche Informationen hervorbringen.

Verworfen ist die Behauptung, Wiederholung an sich verbessere zuverlässig die Genauigkeit, unabhängig von Formulierung und Rückmeldung.
